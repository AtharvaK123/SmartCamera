# Mood music

SmartCam plays these after a face scan, picked by the stress level Presage measures:

| Folder | Plays when stress is | Feel |
|---|---|---|
| `high-stress/` | 67–100 | slow, calming — "Wind down" |
| `moderate-stress/` | 34–66 | gentle, steady — "Ease off" |
| `low-stress/` | 0–33 | upbeat, focused — "Stay in the flow" |

The six songs here were composed for SmartCam: smooth ambient tracks (warm pads with gentle plucks and bells), tagged with a title, artist and genre so Gemini can pick between them.

**To add your own songs:** drop audio files (`.mp3`, `.m4a`, `.ogg`, `.wav`, `.flac`) into a folder and rebuild the app. The file name becomes the song title, so `Ocean_Waves.mp3` shows as "Ocean Waves".

You can also add songs from the phone itself: **Settings → Mood music → Add songs**.
